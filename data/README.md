# Datos del proyecto

## Archivos

| Archivo | Descripción |
|---------|-------------|
| `Nueva_dta.csv` | Serie mensual de variables fiscales y de inversión (2015–2025). Variables principales: deuda predial, recaudación, devengado, FONCOMUN, PIM, morosidad, dummies COVID y estatal, número y monto de proyectos viables. |
| `proyectos.csv` | Inventario detallado de proyectos de inversión de la Municipalidad Distrital de José Leonardo Ortiz (CUI, nombre, estado, montos, avance financiero, etc.). |

**Nota:** Los archivos originales también se encuentran temporalmente en la raíz del repositorio. Se recomienda usar la estructura de carpetas `data/` para mayor claridad.

## Periodo de análisis principal

2018–2025 (96 observaciones mensuales).
